# ポケカ eBay 出品文メーカー（ローカル版）

日本語版ポケモンカードの情報から、eBay 出品用の英語タイトルと説明文を自動生成するツールです。
カード名で検索 → 候補（写真つき）を選ぶだけで、タイトル・説明文が完成します。

- 内蔵カードデータベース: **12,654 枚**（TCGdex のオープンデータより生成）
- カード画像はローカルにダウンロードして同梱する方式（外部サーバーに依存しません）
- 日本語版画像: **9,371 枚**（公式サイト + pcg-search.com より取得済み）

### 収録範囲（重要）

収録している世代: 拡張パック〜ジム拡張2（PMCG）/ neo / e / VS / web / PCG（EX期） /
剣盾（S）/ スカーレット&バイオレット（SV） / メガ（M）。

**DP（ダイヤモンド&パール）・DPt（プラチナ）・BW（ブラック&ホワイト）・ADV・LEGEND・XY・
サン&ムーン（SM）世代（おおむね2003〜2019年）は非対応です。** 検証したところ、この期間は

- TCGdex のオープンデータにカード個票（英語名・カード番号など）がほぼ存在せず、
- 公式サイト（pokemon-card.com）側にもカード番号を確認できるUI要素が存在しない

ため、信頼できるカード番号・英語名・レアリティを再構築する手段がなく、精度を保証できないデータを
出品ツールに混在させるリスクがあるため見送っています。この世代のカードを出品する場合は、
本ツールを使わず手動でタイトル・説明文を作成してください。

## 必要なもの

- Node.js 18 以上（`node -v` で確認）

## セットアップ手順

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. カード画像のダウンロード

公式サイト（pokemon-card.com）と pcg-search.com から日本語版カード画像を取得し、
`public/cards/` に保存します。続けて画像インデックス（`src/imageIndex.json`）を生成します。

```bash
npm run images
```

- 対象は日本語版カード全枚。回線にもよりますが **数時間程度** かかります。
- **途中で止めても大丈夫**です。もう一度 `npm run images` を実行すると、
  ダウンロード済みのファイルはスキップして続きから再開します。
- 画像インデックスだけ再生成したい場合:

```bash
npm run index
```

### 3. アプリの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` が開きます（自動で開かない場合は手動で）。

## 使い方

1. 上部のタブで「シングルカード」か「未開封パック / BOX」を選ぶ
2. シングルの場合、「カード名で検索」に日本語で入力（例: `リザードンex`、`ピカチュウ SAR`）
3. 表示された候補（写真つき）をクリック → フォームに自動入力
4. 状態（NM / LP など）と補足を選ぶ
5. 右側のタイトル・説明文を「コピー」ボタンで取得し、eBay の出品フォームに貼り付け

- タイトルは 80 文字を超えると赤く警告します（eBay の上限）。
- 状態の補足（白かけ等）だけは商品ごとに手入力してください。クレーム防止に一番効きます。

---

## データを更新したいとき

新しいセットが出てカードデータを更新した場合は `npm run images` を再実行してください。
ダウンロード済みのファイルはスキップされ、新しいカードの画像だけ追加されます。

## フォルダ構成

```
ptcg-ebay-tool/
├─ index.html
├─ package.json
├─ vite.config.js
├─ src/
│  ├─ main.jsx           … エントリポイント
│  ├─ App.jsx            … アプリ本体

│  ├─ card-list.json                … スクレイピング対象一覧
│  ├─ scrape-all.mjs               … 画像一括取得（npm run images の実体）
│  ├─ scrape-official-images.mjs   … 公式サイトから日本語JPG取得
│  ├─ scrape-pcg-search.mjs        … pcg-search.com から旧シリーズPNG取得
│  ├─ scrape-pmcg-gym-supplement.mjs … PMCG5/6 トレーナー補完
│  ├─ scrape-missing-sv.mjs        … S/SV 括弧付き名前補完
│  ├─ build-image-index.mjs        … 画像インデックス生成
│  └─ official-card-cache.json     … 公式APIキャッシュ
└─ public/
   └─ cards/{シリーズ}/{セット}/{番号}.jpg|png  … ダウンロードした画像
```

## 注意

- 画像は個人的な出品作業の補助用途で取得しています。取得先の利用規約を尊重してください。
- 出品前には、カード番号・型番・状態が現物と一致しているか必ず確認してください。
  特にトレーナーカードの英語名はデータ側に誤りがある場合があります。
- 本リポジトリは public です。スクレイパー（`scripts/scrape-*.mjs`）を実行する場合は、
  **取得先サーバーに負荷をかけないでください**。同時実行数（`CONCURRENCY`）やリクエスト間隔
  （`DELAY_MS`）を上げる改変はしないでください。デフォルト設定（同時3・間隔400ms程度）を
  推奨します。
