# ポケカ eBay 出品文メーカー（ローカル版）

日本語版ポケモンカードの情報から、eBay 出品用の英語タイトルと説明文を自動生成するツールです。
カード名で検索 → 候補（写真つき）を選ぶだけで、タイトル・説明文が完成します。

- 内蔵カードデータベース: **12,654 枚**（TCGdex のオープンデータより生成）
- カード画像はローカルにダウンロードして同梱する方式（外部サーバーに依存しません）

---

## 必要なもの

- Node.js 18 以上（`node -v` で確認）

## セットアップ手順

Claude Code のターミナルで、プロジェクトのフォルダに移動してから順に実行してください。

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. カード画像のダウンロード（スクレイピング）

TCGdex の画像 CDN から全カードの画像を取得し、`public/cards/` に保存します。
続けて、アプリが使う画像インデックス（`src/imageIndex.json`）を生成します。

```bash
npm run images
```

- 全 12,654 枚が対象です。回線にもよりますが **10〜30 分程度** かかります。
- **途中で止めても大丈夫**です。もう一度 `npm run images` を実行すると、
  ダウンロード済みのファイルはスキップして続きから再開します（レジューム対応）。
- 画像が存在しないカード（TCGdex 未登録）は「未検出」として記録され、
  アプリ上では「画像なし」表示になります。詳細は `scripts/scrape-report.json` を確認してください。

動作確認だけしたい場合は、まず特定セットや少数だけ試せます:

```bash
npm run scrape -- --set SV2a     # ポケモンカード151 だけ
npm run scrape -- --limit 50     # 先頭50枚だけ
npm run index                    # インデックス再生成
```

同時ダウンロード数を変えたいとき（デフォルト12）:

```bash
CONCURRENCY=16 npm run scrape
```

### 3. アプリの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` が開きます（自動で開かない場合は手動で）。

## 使い方

1. 上部のタブで「シングルカード」か「未開封パック / BOX」を選ぶ
2. シングルの場合、「カード名で検索」に日本語で入力（例: `リザードンex`、`ピカチュウ SAR`）
3. 表示された候補（写真つき）をクリック → フォームに自動入力
4. 状態（NM / LP など）と補足を選ぶ
5. 右側のタイトル・説明文を「コピー」ボタンで取得し、eBay の出品フォームに貼り付け

- タイトルは 80 文字を超えると赤く警告します（eBay の上限）。
- 状態の補足（白かけ等）だけは商品ごとに手入力してください。クレーム防止に一番効きます。

---

## データを更新したいとき

新しいセットが出てカードデータを更新したい場合は、TCGdex のデータベースから
`src/cardData.json` を作り直します（生成スクリプトは別途 `scripts/` に追加してください）。
その後 `npm run images` を再実行すれば、新しいカードの画像だけ追加ダウンロードされます。

## フォルダ構成

```
ptcg-ebay-tool/
├─ index.html
├─ package.json
├─ vite.config.js
├─ src/
│  ├─ main.jsx           … エントリポイント
│  ├─ App.jsx            … アプリ本体
│  ├─ cardData.json      … カードデータ（12,654枚）
│  └─ imageIndex.json    … 画像インデックス（npm run index で生成）
├─ scripts/
│  ├─ card-list.json         … スクレイピング対象一覧
│  ├─ scrape-images.mjs      … 画像ダウンロード
│  ├─ build-image-index.mjs  … 画像インデックス生成
│  └─ scrape-report.json     … 実行結果レポート（自動生成）
└─ public/
   └─ cards/{シリーズ}/{セット}/{番号}.webp  … ダウンロードした画像
```

---

## 注意

- 画像は個人的な出品作業の補助用途で取得しています。取得先の利用規約を尊重し、
  短時間に大量アクセスしないよう同時実行数は控えめ（デフォルト12）にしています。
- 出品前には、カード番号・型番・状態が現物と一致しているか必ず確認してください。
  特にトレーナーカードの英語名はデータ側に誤りがある場合があります。
